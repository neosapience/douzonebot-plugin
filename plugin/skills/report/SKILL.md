# 세션 리포트 생성

이번 세션에서 douzonebot 플러그인/스킬을 사용하면서 마주한 모든 문제와 개선점을 구조화된 리포트로 작성합니다. 이 리포트는 플러그인/스킬을 개선하는 데 사용됩니다.

**중요**: 이 스킬은 세션의 **마지막**에 실행합니다. 지금까지의 대화 내용을 전부 분석하여 리포트를 생성합니다.

## 리포트 작성 절차

### 1. 대화 기록 분석

이번 세션의 전체 대화를 되돌아보며 다음을 수집합니다:

- **에러/실패**: 명령이 실패했거나 예상과 다른 결과가 나온 경우
- **비효율**: 불필요한 추가 호출, 우회 작업, 수동 개입이 필요했던 경우
- **UX 문제**: 출력이 부족하거나, 안내가 불명확하거나, 사용자가 혼란을 겪은 경우
- **잘 된 점**: 원활하게 작동한 부분 (개선하지 말아야 할 것들)

### 2. 리포트 출력 형식

아래 형식으로 리포트를 출력합니다. 각 항목에 심각도를 표시합니다.

```
더존봇 플러그인/스킬 세션 리포트

---
N. [심각도] 제목

증상: 무엇이 발생했는지 구체적으로 기술.
원인: 왜 발생했는지 (알 수 있는 경우).
영향: 이로 인해 추가로 필요했던 작업 (추가 호출 수 등).
제안: 어떻게 개선할 수 있는지.

---
```

심각도 기준:
- **[Critical]**: 스킬이 목적을 달성하지 못함. 수동 개입 필수.
- **[Medium]**: 스킬이 작동하지만 비효율적이거나 추가 작업 필요.
- **[Low]**: 사소한 불편. 있으면 좋지만 없어도 작동함.

### 3. 효율성 요약 테이블

리포트 끝에 Phase별 효율성 요약을 포함합니다:

```
세션 효율성 요약

Phase (구간)     | 호출 수 | 불필요한 호출 | 원인
─────────────────┼─────────┼──────────────┼──────────────
Phase 1 (환경)   | N       | N            | ...
Phase 2 (Chrome) | N       | N            | ...
...              | ...     | ...          | ...
합계             | N       | N (%)        |
```

"불필요한 호출"이란: 스킬/코드가 올바르게 작동했다면 필요 없었을 추가 Bash 호출, 탐색, 우회 작업을 의미합니다.

### 4. 분석 관점

리포트 작성 시 다음 관점에서 분석합니다:

- **스킬 문서 (SKILL.md)**: 안내가 부정확하거나 누락된 단계가 있었는지
- **봇 코드**: 에러 처리, 출력, exit code 등이 에이전트/사용자에게 충분한 정보를 제공했는지
- **환경 호환성**: Windows/Mac/Linux 간 차이로 인한 문제
- **에이전트 효율성**: 에이전트가 불필요한 탐색이나 우회를 했는지, 그 원인이 스킬 문서/코드에 있는지

### 5. 제외 사항

다음은 리포트에 포함하지 않습니다:
- 사용자 실수로 인한 문제 (잘못된 입력, 더존 미로그인 등)
- 네트워크/서버 장애 등 외부 요인
- 이미 이번 세션에서 수정 완료된 문제 (단, "이번 세션에서 수정됨"으로 언급은 가능)
